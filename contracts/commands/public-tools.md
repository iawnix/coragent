# Model tool index

Generated by scripts/update_public_contract.mjs. The runtime supplies tool names, descriptions and schemas directly to the model; this index does not register tools. Tools and backend commands share identities; internal commands are not automatically model-visible. Terminal slash commands are separate user interfaces.


Research Memory retains original requirements, problem Nodes, immutable Results and explicit relations. Job Manager owns execution; Artifact Store owns payloads and provenance. Research updates do not gate tools or trigger next_run.
