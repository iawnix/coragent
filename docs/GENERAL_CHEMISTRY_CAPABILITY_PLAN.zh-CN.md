# 通用计算化学研究能力实施计划

日期：2026-10-11。代码基线：`cb291afa`。状态：**批次 A–J 的约定模块开发与确定性验收已完成，并随提交 `c8d408ef` 推送至 main；Gaussian 梯度/NEB 适配已补齐。真实求解器科学基准与真实模型自主研究验收尚未执行，不能据此声称任意反应可自动完成**。

本计划覆盖用户提出的十类问题：多格式输入、端点与复合物准备、机制猜测、候选 TS 搜索、科学验证、多步路径、竞争反应、能量分析、结构与映射比较、独立模块调用。初始规划未检查安装环境；后续实施只读确认本机存在 Gaussian 16 A.03 与 xTB 6.7.1，未发现 QBICS/MECP 安装，不将文件存在视为运行验证。第 2 节保留初始基线，第 9–19 节记录最终实施和范围；未被实施记录明确支持的设计不代表已经可调用。

## 1. 目标与实施原则

目标是让 Agent 按科学问题组合通用方法，保留可追溯的输入、计算、检查和结论。寻找 TS 是组合任务之一；单点、优化、构象搜索、频率、扫描、IRC、结构比较和能量分析必须能够独立使用。

1. 保留 Agent、Task、Node、Job、Artifact、Result 及 Monitor。Node 继续表示研究问题，不引入固定阶段节点、科学审批 Gate 或新的规划循环。
2. 研究关系不决定工具权限，不把 Node 图当作反应网络或计算调度 DAG。失败和不确定结果可以发布，关闭 Node 不要求科学检查通过。
3. 反应名称是知识和可选策略，不是输入、执行或验证的前提。DA 专用几何和检查可保留为显式选择的策略及回归案例，通用入口不得隐式使用。
4. 方法与后端分离。扫描、NEB、构象采样等算法根据实际需要调用能量、梯度或 Hessian；不能因为安装了某个程序就声称整个方法可用。
5. 常用方法提供可复用执行和分析模块；通用 Job 与任务脚本继续开放。能力说明用于选择方法，不形成封闭白名单。
6. 分开记录执行、解析、有限范围的科学检查、Agent 综合判断与任务交付。存在 Artifact 不证明科学成立，某个检查通过也不证明整个机理成立。
7. 同时更新中英文 Skill、接口说明、执行目录和必要的资源摘要。文档中的能力承诺必须匹配执行与解析范围。
8. 采用增量材料契约，不先建设新的中心数据库或大型化学对象框架。复用 Artifact 保存版本化 JSON、结构文件和原始输出，通过 Result 引用。

## 3. 通用材料与能力约定

### 3.1 最小材料模型

字段随具体操作按需要求，不把所有字段变成每次研究的前置手续。

| 材料 | 内容与边界 |
| --- | --- |
| 输入/结构材料 | 原始输入引用、分子图（可未知）、坐标（可缺失）、坐标单位、片段、同位素、电荷、立体化学、来源和推断范围。保留已有几何，不默默重建 |
| 电子态描述 | 多重度、目标态方法/标签、适用时的 root/态特征、占据或波函数来源。root 编号只在指定方法与计算中有意义，不能作为跨几何永久身份 |
| 原子对应材料 | 稳定原子标识、输入行号到规范计算顺序的置换及逆置换、显式 H/同位素、候选映射、对称等价和未决歧义 |
| 构象/复合物集合 | 共同物种/态引用、每个成员的几何与来源、采样和约束条件、聚类与筛选依据。单个几何哈希不等于物种身份 |
| 基元步骤假设 | 参与物种及计量、可选目标端点、预期成断键/内坐标变化、电子态、环境、假设来源。没有产物也能保存待探索假设 |
| 路径/网络材料 | 物种、基元步骤、共享中间体、可逆性和证据引用。独立于 Node 的组织关系 |
| 计算/检查材料 | 方法与程序版本、输入摘要、能量类型、单位、实际态、收敛、解析状态、检查范围与限制、输出及 producer 引用 |
| 能量集合 | 各物种计量、结构/态来源、电子与热来源、温度、标准态、溶剂、近似、相对参考和误差/敏感性说明 |

计算核数、内存和路径属于执行来源。科学可比性依据方法、结构、态和条件判断，不能仅因两次资源不同就认定科学证据不相容。

### 3.2 能力说明

在现有执行目录及方法选择层描述每项能力的：支持任务、输入格式、方法/电子态范围、导数阶数、约束与溶剂能力、解析字段、检查范围、所需环境和证据等级。

区分三类事实：程序声称支持某任务；项目已实现相应准备/解析；目标环境已验证可运行。每项分别记录，不能用一个 `available=true` 替代。

优先复用 `domains/chemical/execution.json` 和现有 environment check。只有现有 schema 无法表达必要事实时才扩展 `backend/src/research_agent/application/execution_schema.json`，不创建另一套竞争目录。

## 4. 分阶段实施

### P0：纠正能力边界与通用入口中的专用假设

依赖：无。目标：首先消除错误承诺和错误证据解释。

工作项：

- 清点 executor、validator、acceptance profile 与 Skill 的实际对应，标明内置、外部/脚本、未核实及明确不支持的范围。
- 通用 TS/IRC 文档不再默认推荐 DA 专用验证器；现有 DA 检查明确标注适用范围，超范围返回未评估及具体原因，不作为化学反证。
- 在分子图、映射、准备策略和验证选择中消除对反应名称的隐式依赖，保留旧 DA 材料与显式调用的可读性。
- 为 Gaussian 能量增加来源/类型判别。未实现的目标方法或电子态不能将参考 SCF 能量填成所请求的最终能量；保留原始日志和明确诊断。
- 修正文档与实现漂移，包括 IRC Hessian 使用说明。解析失败、方法未支持和科学检查失败必须区分。

主要范围：`domains/chemical/execution.json`、`skills/_shared/{reaction_checks,path_validation}.py`、Gaussian parser/input runner、validation/candidate-generation/method-selection 的中英文 Skill 与参考。此处 `skills/` 均指 `domains/chemical/skills/`。

完成标准：非 DA 输入不会被默认按 DA 验收；已有 DA 回归语义不变；模拟激发态/相关方法输出不会误报 SCF 参考能为目标能量；能力矩阵的每项均有实现或缺口依据。

### P1：输入、物种、映射与结构比较

依赖：P0 的能力约定。目标：所有后续模块使用保真、可追溯的材料。

工作项：

- 统一名称、SMILES、XYZ 输入适配，名称查询失败进入有来源的候选推断；保留用户已有坐标和复合物取向。
- 明确孤立物种、多个独立反应物和已定位复合物。缺失电荷/态/键级记录为未知或带依据的假设；只有影响可执行选择且无法合理分支时才请求补充。
- 在现有显式映射核验基础上，提供有界映射候选：元素/同位素/电荷与用户约束先行，图匹配或有文档算法产生候选；保留非唯一对应，不保证总能生成正确原子轨迹。
- 保存置换及逆置换，坐标、梯度、Hessian、振动向量等按各自张量结构一致转换。已有生产输出不可原地修改。
- 拆开图身份、立体化学、构象几何和电子态比较。构象比较支持对齐 RMSD、关键内坐标、对称等价与片段取向；不能通过反射对齐误合并对映体。
- 迁移 H 必须保留显式身份；XYZ 推断键级和金属配位等歧义输出未确定结论，不能强制宣告相同/不同。

主要范围：material-preparation、`_shared/chemical_identity.py`、`_shared/reaction_checks.py`、candidate-generation 的原子顺序处理；版本化材料约定放在对应领域资源中。

完成标准：同一输入保留原坐标；乱序结构可往返恢复；旋转平移和对称等价不造成错误差异；对映体、不同质子化状态和明确异构体不错误合并；缺失 P 不妨碍独立优化/单点任务；显式 H 转移与同位素的身份不丢失。

### P2：独立计算、构象/复合物准备与候选搜索

依赖：P1；可复用部分执行封装在 P0 后先做。目标：把常用方法从临场脚本提升为可测试模块。

工作项：

- 保持现有 Gaussian/xTB/CF22D 单点、优化、频率与 TS 入口，补齐统一输出的结构/态/能量来源。
- 实现 CREST 的有界执行及集合解析，核对版本、输出完整性、成员身份和能量行数；支持集合聚类、低成本筛选和选定成员精修。
- 提供多片段复合物的有界取向/接近采样，输入可以是独立片段或用户复合物；明确碰撞检查、可选约束、采样范围和随机种子。不宣称穷尽。
- 统一一维/二维弛豫扫描的控制、逐点目标/实际坐标、约束、收敛、能量和失败点。Gaussian 与 xTB 使用各自真实接口；支持中断后按已收集材料继续，不能盲目重跑未知派发。
- QST2/QST3 准备接受显式相容端点及可选 TS 猜测，不依赖命名反应；端点是否属于同一基元步骤由研究假设和后续证据判断。
- 实现通用 NEB runner，声明映射、插值、image、优化器、climbing-image 策略和力收敛标准。先建立能量/梯度 calculator 合同及确定性测试，再接入适用的 xTB 实现；Gaussian calculator 在其梯度准备/解析与成本检查具备后接入。
- 统一候选材料来源。扫描峰值、NEB 高能 image、QST 初猜和插值几何都保持“候选”身份；精修与验证另行执行。

主要范围：crest、candidate-generation、xtb、gaussian、cf22d、method-selection、执行目录及所需环境锁。新增算法模块放在领域目录，使用既有 Job 生命周期。

完成标准：各方法可单独提交与收集；没有反应名称也能准备并执行；失败点和部分集合可恢复；calculator 的单位、力/梯度符号和原子顺序有独立数值检查；只有能量而没有梯度的绑定不会被误选用于要求梯度的方法。

### P3：通用驻点、振动模式与连通性检查

依赖：P1；可与 P2 的执行工作交错实施。目标：检查由科学性质与显式假设决定。

工作项：

- 将程序特有 parser 与反应无关检查分离，形成可单独调用的收敛、频率/模式、路径完整性与端点比较能力。
- 经典一阶鞍点检查保留完整频率和数值阈值，按几何类别处理振动自由度，检查约束条件；小负频不得静默删除，频率计数不能替代模式归属。
- 模式分析接受任意声明的成断键、质子转移、角度/二面角或组合坐标，报告位移/投影、正负扰动和限制。模式整体换号不改变判断，不要求所有坐标变化等幅或固定两条成键。
- IRC 检查同一来源结构/态、方向、终止和完整性；保留最大步数截断等情况。端点未到势阱时提出继续或优化需求，再用独立身份比较归属。
- 双向归属允许方向交换；到达意外中间体要记录实际结果，不能强行匹配用户目标。图身份一致不自动说明构象和电子态连续。
- 普通 TS、无势垒、受约束路径和跨态研究使用不同适用性说明。超范围输出未评估，不通用套用“一个虚频 + IRC”。
- DA 特有判据作为显式附加检查保留，通用检查不导入 DA 拓扑。旧 validator/profile 固定原版本语义，新语义使用明确的新版本或新入口。

主要范围：validation、irc、`_shared/path_validation.py`、Gaussian/CF22D 解析材料、执行目录的验证器声明。

完成标准：质子转移、单键变化、扭转和非 DA 重排可得到有范围的检查；无关虚频、多虚频、缺少模式、截断 IRC、错误端点及错误电子态均不会获得完整通过结论。通过检查不强制关闭 Node，也不成为试算的准入条件。

### P4：热化学、构象集合、能垒与能量剖面

依赖：P1 和基本解析；驻点证据复用 P3。目标：把可比较数值及其假设保存为独立分析产物。

工作项：

- 复用 Gaussian 热校正解析和 CF22D RRHO，建立 E、ZPE、H、G 的明确数量与单位，缺字段不能用零补齐。
- 实现温度/标准态换算、显式计量的反应能和势垒计算；气相、溶液、浓度和溶剂模型分别记录。
- 支持明确声明的高层级单点与低层级热校正组合，检查结构/态相容性，防止重复计入 ZPE、热项或溶剂修正。
- 实现一种有文档的低频处理方案和构象集合自由能，记录阈值、简并度、温度及采样限制。TS 的不稳定模式与稳定低频模式分开处理。
- 输出共同参考的能量表、剖面及数据文件，包含复合物形成、催化剂、旁观物种和全部计量参与者。
- 扫描数据输出有限维势能切片；离散驻点能量剖面不标成完整势能面。自由能采样作为独立、明确范围的扩展，不由静态扫描冒充。

主要范围：energetics 新增可复用执行/分析脚本，Gaussian/CF22D 输出合同，report 的数据消费。

完成标准：单位和标准态变换有独立数值依据；混用态/方法/不相容结构有明确诊断；缺失校正与真实零值区分；计量、集合简并度及高低层级组合的重复计数错误能检出；只有电子能时不输出伪造的自由能。

### P5：机制假设、多步路径与竞争动力学

依赖：P1–P4 的可用子集。目标：组合上述模块，而不增加固定科学工作流。

工作项：

- 扩展 reaction-investigation 的条件化决策：R-only、已给 R/P、复合物、催化/溶剂参与、自旋变化和竞争路径分别给出可检验假设及探索预算。
- 机制材料区分初始假设、计算观察、支持/冲突和未探索部分；产物猜测始终保留来源，避免计算开始后丢失假设身份。
- 多步路径材料引用每一步与共享中间体证据，核验原子/计量/态连续性和缺失步骤。发现中间体或意外出口时可扩展路径，不能把总 R/P 当成单个 QST2 任务。
- 先实现适用范围明确的基元 TST 与共同前体竞争分支比较；记录浓度、可逆性、传输系数以及未处理的隧穿/再穿越/扩散。
- 对包含可逆反应、构象互变、耗尽或催化循环的情况，实现显式计量网络与质量作用动力学分析，核对守恒、初始条件和数值误差；不使用“最低局部势垒”替代网络结论。
- 报告分别给出热力学排序、动力学预测、条件敏感性和覆盖范围。没有充分采样时只能声称“所比较集合中”，不声称全局最优。
- 验收 Agent 在 Job 等待、失败、上下文恢复和方法切换后的持续推进；只在有独立研究问题时拆 Node。

主要范围：reaction-investigation、energetics、report、research-workflow 的使用示例及原生 Agent 集成测试。Task/Memory 内核不新增化学真值裁判。

完成标准：确定性两步路径不会遗漏中间体证据；动力学与热力学排序相反的案例正确区分；不同前体不能直接套共同前体分支比；缺 P 时有有界探索和未决记录；证据不足只形成进展/阻塞说明，不能降低原交付目标后宣告成功。

### P6：电子激发态与跨态能力扩展

依赖：P0 的能量边界、P1 的态描述；与后期 P2–P5 可按模块交错。目标：非基态能力有真实执行、解析和态证据。

工作项：

- 第一批选择明确支持范围的 Gaussian TDDFT/TDA 激发态单点与优化；核对目标态能量、梯度、收敛和可获得的态特征，记录 root 与参考波函数关系。
- 提供沿几何变化的态跟踪与歧义诊断；先实现可验证的方法，不能只比较 root 数字。近简并、root flipping 或特征不足时标记不能确认。
- 支持不同多重度表面的独立计算和比较，核对实际波函数、自旋污染与相容方法；指定多重度不证明获得全局最低态。
- 跨态扩展先评估并绑定一个实际可用的 MECP/交叉点实现（可包含经核实的 QBICS），要求能量差、约束驻点和态身份的独立检查。没有合适求解器时明确缺口，不能替换为普通 TS。
- 圆锥交叉、非绝热动力学及多参考方法作为单独范围，只有相应方法、导数、解析与验证具备时发布支持；不得被“激发态支持”笼统覆盖。

主要范围：method-selection、gaussian、qbics 或选定外部方法适配、validation、电子态材料及科学回归。

完成标准：激发态能量不读成参考 SCF 能；态切换不能静默通过；不支持的导数/方法给出具体原因；跨态检查不能由普通频率/IRC 检查冒充。任何真实求解器未验证部分保留未验证标签。

## 6. 验收设计

### 6.1 证据分层

| 层次 | 验证内容 | 不能据此声称 |
| --- | --- | --- |
| 合同与数值单元验证 | 原子置换、单位、守恒、能量组合、解析缺字段、算法在已知函数上的表现 | 真实化学计算收敛 |

## 7. 兼容、风险与完成口径

旧 Artifact 和 Result 不重写。新增材料以新版本保存，旧 DA profile 保持其有限语义；不能修改旧 validator 的意义后仍使用同一版本。需要升级使用的材料由新分析产出引用旧来源，失败不破坏原始记录。

主要风险及处理：

- 范围过大：按 A–J 交付，每批声明已支持和未验证范围；缺少某个高级模块不妨碍已独立验收的基础模块使用。
- 化学身份和映射歧义：保存候选和限制，区分图等价与真实轨迹，不强制产生唯一答案。
- 电子态与能量误解析：先做 P0 的类型保护，再扩展方法；保留原始输出用于复核。
- 构象/网络组合爆炸：预算约束、筛选依据和未探索范围可见，达到边界不能宣称穷尽。
- 方法间结论迁移：低层级候选转高层级后重新检查；共享材料不意味着证据自动跨方法成立。
- 文档继续超前于实现：每批同步能力清单、调用示例和测试证据等级；“可写脚本”与“内置完整支持”分别表述。

阶段完成要求是约定接口、适用范围和验收场景落实，不能因为写完 Skill 即标记科学能力完成。整个计划的交付报告需逐项回应十类需求，给出已实现模块、独立调用示例、支持后端与电子态、通过的证据层次和仍然明确排除的范围。
