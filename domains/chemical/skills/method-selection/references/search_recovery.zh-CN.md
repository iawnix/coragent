# 搜索诊断与故障恢复

[English](search_recovery.md)

依据收集的原始证据区分执行故障、数值失败与化学问题。保留原请求、日志和 checkpoint，
修改假设/参数后创建新的不可变 Job；对 running/unknown 先核对状态，避免重复派发。
独立假设可在预算内并行，不设置固定失败次数、强制阶段顺序或反应专用状态机。
观察与下一步决策记录在当前研究 Node。

| 现象 | 先检查什么 | 根据证据恢复 |
| --- | --- | --- |
| 导入、程序、许可、排队或传输失败 | 选定绑定、激活、路径、stderr、调度器和 Job 状态 | 修复执行路径，不推断为化学失败，也不悄悄换方法 |
| route/output 不匹配 | 实际暂存输入、回显 route、Link1、checkpoint 状态和有效方法/基组 | 修正准备或解析范围，扰动种子解决不了 route 错误 |
| SCF 不收敛/态不稳 | 短接触、电荷/自旋、占据、能量/S² 趋势及可用稳定性/态特征证据 | 有依据地调整初始轨道、阻尼、求解选项或电子方法；收敛不等于态连续 |
| 几何/TS 优化停滞 | 最后接受的结构、力/位移趋势、信赖半径、Hessian 更新及局部畸变 | 按原因考虑重算 Hessian、减步长、换内部/Cartesian 坐标或调整积分网格，不一次乱改所有参数 |
| 多个/很小的虚频 | 位移向量、阈值、松散片段/扭转、网格及平移旋转污染 | 数值问题收紧后重算，化学问题重新采样/构造；不能删频率凑数量 |
| NEB 尖峰、聚集、急弯 | 逐 image 能量/力、碰撞、映射、端点、旁观片段和多势阱 | 调整路径/IDPP、image 密度或构象/基元步骤；加步数不能修复错映射 |
| IRC 提前终止 | 积分终止原因、点数预算、步长、力趋势与末端结构 | 有依据地续算/调整步长和 Hessian，优化端点后再判断连接失败 |
| 双向 IRC 到同一势阱 | 先排除截断，核对模式位移与 TS 身份 | 检查位移方向/幅度和候选特征；反复完整同势阱证据应促使修订候选/基元假设 |
| 正常终止却解析失败 | 原始方法/section、单位、原子序、末帧和不支持的物理量 | 保留原始数据并选经核验适配器，不能拿早先 SCF 能量顶替目标能量 |

## 复用中断计算

checkpoint 可能含几何、轨道和力常数；存在不代表相容或计算完成。暂存复用前核对
原子序、电荷/自旋、方法与生成 section。新 Hessian 有额外成本，应计入预算。
不盲目重复状态未知的 Job，不覆盖历史记录。

失败轨迹的重启帧依据有限力、局部几何、反应坐标进展和电子态一致性选择，并记录帧
身份和理由。TS 优化是找鞍点，最低能帧可能已落入极小点，不能默认选择。
NEB 新初始路径应来自已收集、审查过且结构—能量配对的证据；v2 不自动恢复 FIRE/BFGS 状态。

## 局部化学诊断

检查预期/非预期质子转移、短接触、片段塌陷、位阻接近、旁观基团参与及角度/扭转。
使用明确原子 ID 和合适的局部对齐；全局 RMSD 可能掩盖反应中心变化，局部对齐可揭示
旁观片段移动。[局部工具](../../chemical-input/references/local_diagnostics.zh-CN.md)
只描述几何；键级、电荷、自旋密度、轨道特征需另取电子证据，共价半径阈值不证明键或机制。
结合[轨迹工具](../../report/references/research_tools.zh-CN.md)查看完整变化。

重复证据挑战当前路线时，重新考虑协同/分步、质子穿梭、溶剂/催化剂参与、构象/取向、
映射、自旋与竞争位点，设计能区分假设的计算。微扰种子应回答具体未决问题。
经典 TS 仍需驻点、合适虚频模式和端点连接；激发/跨态另用相应判据。
