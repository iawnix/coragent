# 能力地图

选择能够回答当前问题的最小工具。工具结果是研究材料和假设更新，不是强制下一步的流程结论。

| 当前问题 | 工具 | 输出 | 边界 |
| --- | --- | --- | --- |
| 哪些映射原子和片段构成反应中心？ | `chemical.reactive-sites@1` | 固定/移动角色、局部坐标系、备选反应面和距离提示 | 需要显式分子图和 `bond_changes`；不推断产物或机理 |
| 分离片段应如何相向排列？ | `chemical.reactive-pose@1` | 含距离、圆锥、扭转和安全诊断的确定性取向集合 | 不排序能量、不搜索内部构象、不认证 TS |
| 应该尝试哪些分子内构象？ | `chemical.seed@1`、CREST | 初始构象或构象集合 | 不决定反应中心 |
| 取向在保持反应坐标时能否放松？ | `chemical.scan-xtb@1` | 受限优化结构、实际坐标和无约束物理能量 | 单点约束放松不是鞍点搜索 |
| 端点之间能否形成合理路径？ | QST、受限扫描、GSM/NEB 工具 | 路径图像和计算证据 | 端点及原子对应关系必须先准备好 |
| 候选是否是 TS？ | 频率和 IRC 验证 | 虚频和双向下坡路径证据 | 几何评分、扫描最高点或 NEB 图像都不是 TS 证明 |

## 选择建议

反应中心已经映射时，先分析反应中心，再采样片段取向。如果输入来自单个 SMILES 嵌入，应先
增加内部构象，再扩大取向搜索。如果无约束优化使取向塌缩，返回到受限 xTB 点，而不是接受这个
极小值。如果多个位点或反应面仍有化学可能性，将它们作为独立假设运行，之后再比较证据。

执行器中的硬编码检查应限制在输入格式、坐标安全、声明约束和来源一致性。反应类型先验以及是否
扩大采样、重试或停止，应由 Agent 管理假设。
