# 恢复手册

根据失败证据修订假设，不要静默重复同一个输入。每次重试都应改变一个声明变量或增加证据。

| 现象 | 首要解释 | 下一步 |
| --- | --- | --- |
| `atomic_clash` 或严重重叠 | 刚性摆放进入了非反应接触 | 增大距离、采样其他反应面/圆锥，或换构象 |
| 取向生成后移动片段仍很远 | 固定/移动角色或局部坐标系不合适 | 检查 `reactive-sites`，反转片段角色假设并重新生成 |
| `multi_pair_rigid_fit_residual` | 一个刚性取向无法同时满足这些接触 | 拆分假设、改变距离集合，或使用柔性约束扫描 |
| 约束 xTB 点偏离容差并塌缩 | 约束太弱，或取向缺少化学依据 | 在预算内增强约束、改变取向，或保留为拒绝证据 |
| 无约束优化立即返回分离反应物 | 过早释放了 TS 取向坐标 | 返回约束点，或先做短的受限扫描 |
| QST/NEB 立即断裂或形成无关的键 | 端点或初始图像不相容 | 重新检查映射、反应中心距离和端点构象，再启动路径搜索 |
| 一个候选成功而其他候选失败 | 证据偏向一个势阱，但不证明其唯一性 | 保留失败候选，在研究报告中比较诊断 |
| 没有化学上有支持的位点 | 缺少显式键变化或产物映射 | 使用 `chemical.reaction@1`，补齐映射，或保留反应中心未决 |

不要把工具的 `safe` 结论转换成 TS 结论。安全取向只是适合进入下一步计算的候选几何。
