# 路径假设

路径假设描述相互连通的一组基元步骤假设，以及中间体或势阱 身份。不能从单个
过渡态结果或研究 Node 拓扑推断整条路径得到支持。

在已有 Node 的 plan、note 和 Result 中明确描述步骤、物种身份及其化学关系。化学步骤和候选分支不自动对应新 Node。研究 Node 的 requires 表达研究依赖，不定义化学连通性，也不替代机理证据。

评审路径时，为有序步骤引用、端点/中间体 身份、共享物种一致性、电荷/自旋或态连续性
及其他已核验事实创建研究记录。为未解决分支、缺失步骤、冲突归属或局限创建
研究记录。每个研究记录都引用来源 Artifact。

复用已有 node_id：观察、科学判据和下一步决策用 research_update 的 note，可复用结论用 research_result，并引用实际收集的材料与局限。同一发现不在两种记录或任务进展中重复抄写。计算完成不等于科学结论成立，也不要求新 Node 或 Result。
