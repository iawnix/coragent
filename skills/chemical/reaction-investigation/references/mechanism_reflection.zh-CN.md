#假设反思

在相关已有 Node 的 plan 中明确机理假设、预测、可证伪观察和科学前提，思路变化保留在 note 中。不需要创建单独的假设对象。竞争方案成为需要独立持续判断的研究目标时，才用 alternative_to 关联问题；形成值得引用的结论时，在 Result 中结合依据解释支持与冲突。

对每个假设询问：

- 哪项事实可以将它与替代解释区分；
- 它假设什么电子态、自旋、电荷、构象与环境；
- 它描述一个基元步骤，还是由多个步骤组成的路径；
- 哪种意外结果会使当前问题框架失效；
- 哪些验证维度是基础要求，哪些是可选项。

继续当前 Node 的尝试，获取能够区分假设的观察；只有独立问题才创建新 Node。搜索失败可能表示方法不合适、候选构造
错误、缺少构象或假设本身错误；在 Artifact 给出依据前，保持这些解释相互独立。

复用已有 node_id：观察、科学判据和下一步决策用 research_update 的 note，可复用结论用 research_result，并引用实际收集的材料与局限。同一发现不在两种记录或任务进展中重复抄写。计算完成不等于科学结论成立，也不要求新 Node 或 Result。
